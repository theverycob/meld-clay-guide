What is in your download?

The installer ZIP, this offline guide, three editable animals, the Ember dragon learning project, a material playground, an eye playground, join and form studies, a crack-quality study, and the license. Each animal has its own collection; expand its Editable Parts collection to see the blockout.

Find a setting quickly

Use Search settings at the top of the Meld Clay panel or in the 3D Viewport header. The header field stays available when the sidebar scrolls; its filter button opens the matching controls. Both fields share one query. Type crack, pressure, hold or move to find controls and actions such as Move Whole Model. Matching settings appear as editable controls, grouped by their section, including controls normally behind collapsed sections. Search follows the selected clay model or eye. Disabled results show the setting or selection they require. Clear the search with its × to return to the normal panels. Searching itself changes no model settings.

This guide is for Meld Clay v1. Tested on Windows in Blender 4.5.0 and 5.1.2. Other operating systems and Blender versions have not been tested in this release.

GET SET UP

Install and update Meld Clay

First installation

  1. Extract the large Meld-Clay-v1.zip customer download.
  2. Inside its Installer folder, find meld_clay-1.0.0.zip. Leave this smaller ZIP zipped.
  3. In Blender, open Edit → Preferences → Add-ons. Open the small menu at the top right and choose Install from Disk.
  4. Select meld_clay-1.0.0.zip. Confirm installation and enable Meld Clay if Blender asks.
  5. Move your pointer into the 3D Viewport, press N, and open the Meld Clay tab.
Two ZIPs, two jobs. Extract the customer download. Install the smaller installer ZIP. Dragging the entire customer bundle into Blender will not install the add-on.

Requirements

Blender 4.5 or newer is required. This release was tested in Blender 4.5.0 and 5.1.2 on Windows. No external Python packages, paid renderer, textures, accounts or online connection are required to use the add-on. Cycles and Material Preview show the clay finishes; Solid shading is useful for shaping but does not show the full shader.

Updating an existing installation

  1. Save a separate copy of your scene.
  2. Install the newer installer ZIP using the same steps above.
  3. Select an existing live clay model. Its saved body shape stays unchanged in Shape style: Custom. Choose a named Shape style to apply the new clay recipe, or Enable Clay Shaping to expose individual rounding and pressure controls with zero added effect. Saved per-part Hold Shape values are preserved. Soft Dough adopts the current surface-curve system when you edit its crack settings; no capture or update button is needed. Use Update Thumbprints or Update Form Variation only when offered. Softening has a separate, explicit choice: Update Softening under Shape & Melding. Choosing a Shape style or Enable Clay Shaping also updates softening as needed. Otherwise, the saved method stays in place until you choose Update Softening. New models already use the current method. Read the cleanup and softening guide.

Installation preserves saved models. Detail updates retain previous node/material data as backups. If you need to return to an older release, use its original ZIP and the corresponding saved scene copy. Older versions may not understand every new control. Baked meshes are independent and are not automatically rebuilt.

If the tab does not appear

Check that Meld Clay is enabled in Preferences, then look for its tab in a 3D Viewport, rather than the Shader Editor or Properties window. If an upgrade reports a Python import error, restart Blender and install the new ZIP again. Include the full error when requesting help.

5-MINUTE START

Create and edit a clay model

  1. In Object Mode, add a few UV spheres or cubes for a body, head and feet. Scale and move them until adjacent parts overlap.
  2. Select the parts, then click Meld Selected Parts in the Meld Clay sidebar.
  3. Open Clay Finish and choose Soft Dough. Switch the viewport to Material Preview to see it.
  4. Under Shape & Melding, start with Shape style: Palm rolled. Try Thumb pressed or Gently kneaded for a different body feel. Choose your finish first, then your Shape style: some finish presets also set the earlier surface noise. New models already start at Palm rolled.
  5. Click Edit Parts. Move or scale a cage: the clay follows. The original low-poly geometry remains editable.
  6. Click Finish Editing Parts when you want an unobstructed view.
Want a ready-made starting point? Open Examples → Meld-Clay-Animals.blend, select one animal’s clay surface, and click Edit Parts. Or use the built-in demo button when no clay model is selected.

Good building blocks

Use closed mesh solids with a little overlap. Thin sheets, open meshes, tiny floating details and barely touching surfaces may disappear or stay separate at low resolution. Curves and text can be converted to mesh in Blender first; this add-on’s melding input is mesh parts.

Adding or removing a part

Click the finished clay model in the scene and choose Edit Parts, then select the additional mesh. The target stays on that model when you select a loose part. Check the target name and click Add Selected: the part count increases and the surface updates immediately. The original becomes an editable source cage; it is not deleted. The added shape takes the target model's clay finish and surface settings.

Select an owned source and click Remove to detach it; the surface updates and the separate original returns. Join rules involving that part are removed too. Other joins keep their settings, and Undo restores the removed part and its rules together. If you added a part to the wrong model, edit that model's parts, select the misplaced source and Remove it, then add it to the intended model. For narrow horns or spikes, use the source part's Hold Shape under Join Controls to reduce kneading. Leave an accent separate if it should keep its own finish. To detach everything, use Restore Original Parts in Finish & Utilities.

If Meld Selected Parts is gray, read the hint below it: the selection may already belong to a clay model, contain an eye, or be in Edit Mode. Use Edit Parts to change an existing model.

SHAPE THE CLAY

Roll it, press it, knead it

Choose a Shape style for the body feel, then adjust only what you want to change. The recipes round your editable source pieces and add smooth, broad hand pressure before they meld.

New models start at Palm rolled. Choose Thumb pressed for fewer, broader compressions or Gently kneaded for overlapping soft squeezes. Keep Surface cleanup Auto for small remeshing steps. The named styles set Knead / soften 45 and Source rounding 1; pressure follows the size of each source piece. Your saved per-part Hold Shape stays in place.

Actual Blender renders of the same 54-face source ball with Hold Shape 0, the same seed, finish and lighting. Click a render to inspect it. These show the shape recipes; the fingerprints and clay finish are separate material controls.

ControlWhat to expect
Shape stylePalm rolled, Thumb pressed or Gently kneaded sets a complete body-shaping recipe. Custom keeps your current values. Editing a recipe value switches the dropdown to Custom without resetting the other values. A finish preset can also set the earlier surface noise and make the style read Custom; choose your finish first, then your Shape style for its complete recipe.
Source roundingTurn coarse source contours into a curved form before melding. 0 keeps the source contours; 1 allows full chosen rounding. Knead / soften and Hold Shape also affect the result.
Hand pressureBroad geometry squeezes, as a percentage of each source piece radius. 0 adds no pressure. It is separate from material grain and fingerprints.
Pressure areasHow many broad squeeze areas surround each source piece. More areas give more overlapping changes to the shape.
Pressure breadthHow far each squeeze spreads. Higher values produce broader, gentler areas; lower values concentrate them.
Knead / soften0 disables source rounding as well as artistic kneading. 45 gives the full selected Source rounding; higher values continue softening the melded surface. Hand pressure remains independent.
Surface cleanupAuto reduces small remeshing steps, even at Knead / soften 0 or on held parts. Off skips this cleanup; it does not turn off hand pressure or material texture. Cleanup alone cannot turn a faceted source into a round clay ball.
ResolutionHow finely the underlying surface is rebuilt. Higher values allow smaller details, with more processing and memory.
Hold ShapeProtect one source part from rounding and hand pressure. On a one-part model, edit it directly below Knead / soften or search hold. On a multi-part model, use Edit Parts, select a source, and adjust Hold Shape in Join Controls.
More shape controlsContains Form variation and the earlier Hand-shaped amount/scale noise. These remain available for saved looks and rougher effects. Named Shape styles set Form variation and Hand-shaped amount to 0.

A quick clay-ball exercise

  1. Save a working copy and select a one-part clay ball. Choose Palm rolled. If its source has protection, set Hold Shape 0 below Knead / soften.
  2. Compare Palm rolled → Thumb pressed → Gently kneaded using the same Random seed. Orbit the silhouette and back of the ball.
  3. Keep your favorite style, then change Hand pressure gradually. The dropdown now says Custom because you made your own recipe. Adjust Pressure breadth if a squeeze is too concentrated.
  4. Try Knead / soften 0 → 45 → 120 → 45. At zero, source rounding stops; pressure can still be visible. Use lower Hand pressure or Source rounding for a gentler change.
  5. Let adaptive preview finish, or use Full Quality Now. In Solid shading, a MatCap with Color set to Object and optional Cavity reveals the actual surface. Return to Material Preview to judge the finish.

Keep fingers, knuckles and deliberate small details

To protect a particular part, use Edit Parts, select its source and increase Hold Shape in Join Controls. Lower Knead / soften, Source rounding or Hand pressure if the whole model changes too far. Compare seams and small tips after a shape change: the existing joins, cracks and bites follow the changed surface. The presets retain the source meshes and join rules, but do not guarantee every small contour.

Existing models: choose when to change

Opening an older file keeps its saved body shape in Custom. Choose a named Shape style to adopt a new recipe, or use Enable Clay Shaping for zero added rounding and pressure before adjusting individual controls. Existing Hold Shape values are preserved, so a protected low-poly ball may need less Hold before it rounds fully. If an old model asks for Update Form Variation, run that prerequisite first. Update Softening is also available for older softening graphs; enabling the new clay shaping updates softening as needed. These explicit updates retain previous data for recovery.

Shape & Melding Copy/Paste includes the shape recipe and individual shaping values, Surface cleanup, preview preferences and Random seed. It does not copy source geometry, part placement, joins, materials or per-part Hold Shape. An older destination may ask for Update Softening and Enable Clay Shaping first. A copied style adapts its pressure to the destination pieces. A copy from before clay shaping existed sets the new rounding and pressure to 0 and selects Custom, retaining the destination’s shaping method. A pre-cleanup copy retains the destination’s cleanup choice; an earlier Auto/Off copy transfers that choice. Read the clipboard boundaries.

SHAPE & CHARACTER

Join rules and Hold Shape

Edit one connection

  1. Click Edit Parts.
  2. Select one cage, then Shift-select the cage it touches.
  3. Open Join Controls and click Edit Selected Join. These two selected parts determine the rule you edit.
  4. Choose the style and adjust its settings. Hide Cages near the top clears your view; cages also pause automatically during crease edits and return after about 1.5 seconds.
ControlUse it for
BlendedA soft transition between overlapping parts.
PressedAn indented seam, as though separate lumps were pressed together.
Crease strengthHow pronounced the indentation is. Start small.
Crease widthHow broadly the seam spreads around the contact.
Hold ShapePreserve more of one part’s outline. This belongs to the part and can affect every contact involving it.

A model made from one source also exposes Hold Shape in Shape & Melding and search. It is the same source-part value; you do not need a join rule or Edit Parts to use it.

Different legs and head seams?

Yes: select each pair and give it its own rule. A leg–body rule and head–body rule can have different settings. Hold Shape is shared by the part, and nearby seam influences can overlap on the same body. Hold Shape protects source rounding, kneading and hand pressure while Auto cleanup still reduces small remeshing steps around held parts and joins. The controls do not create fully isolated patches of topology for each pair.

Copy a join you like

  1. Edit the source join and click Copy Settings.
  2. Select the destination pair and click Edit Selected Join.
  3. Click Paste Settings.

This transfers the join style and crease settings. Check the destination parts’ Hold Shape separately because it is a part setting.

Selection feels confusing?

Selected parts, Saved join rules and Editing this join are separate boxes. A red notice identifies a selected pair with no rule, or a listed rule that differs from your selection. The selected pair and the highlighted list row can refer to different joins. Edit Selected Join follows your two selected cages. Edit Listed Join follows the highlighted rule. Removing a rule is not necessary to select another pair. Object identity, rather than the displayed name, identifies a part.

Material presets and finish controls

Pick a preset under Clay Finish, then change its color, roughness and surface details. Presets are starting points, not locked looks.

Customize a finish, then reuse it

Choose Dry Cracked Earth in Clay Finish. Its preset also selects Fingerprints & Cracks → Crack style: Dry Fractures and sets broad bumps under Shape & Melding. These controls remain available separately after choosing the preset.

  1. In Clay Finish, choose your two colors, then adjust Color mixing, Color variation and Color variation seed to arrange the pigment.
  2. In Fingerprints & Cracks, set Crack width to Custom and try Width factor 1.5 → 2.0 for wider openings, Crack displacement 0.60 → 0.80 for deeper creases, or Fine fissures 0.06 → 0.20 for more interior shader creases. Lowering Fine fissures removes branches while retaining the surviving cracks’ color, depth and location. Crack color changes their pigment. Crack scale changes connected cell size; use width when paths should stay put. See the crack controls.
  3. Copy Clay Finish, click another finished clay model in the scene, then Paste beside Clay Finish once. Your color seed and customized cracks come with it. Generated model names may differ from their original parts' names.
  4. To combine another palette with these cracks, first choose Smooth Baked on a spare model. Copy and paste only Fingerprints & Cracks from your earth model. The baked colors, color seed and optical finish remain. Crack color is part of the pasted surface settings; adjust it or reset it to automatic for the new palette.

You can also select Dry Fractures directly on any built-in clay finish. Start with Crack scale 1, Layout density 5, Crack width Medium, displacement 0.2, coverage 0.7, Fine fissures 0.08 and Standard quality for a modest combination. Choose the material preset first, then customize cracks; reselecting a preset reapplies its appearance settings. Shape & Melding controls broad bumps separately.

Copy settings between clay models

Use the Copy icon at the right of Clay Finish, Shape & Melding or Fingerprints & Cracks. Select the destination model and click Paste beside the same title. Each section has its own clipboard. Clay Finish includes colors, optical settings, fingerprints and cracks, so a customized Dry Cracked Earth finish appears with one paste. It uses the copied values, not a reset to preset defaults. Use Fingerprints & Cracks to transfer only surface details. Shape includes the chosen Shape style and its rounding/pressure values, Surface cleanup, preview preferences and Random seed. Copying into an older model may first require Update Softening and Enable Clay Shaping on that destination; follow the message before pasting. A copy from before clay shaping existed sets new rounding and pressure to 0 and selects Custom, retaining the destination’s shaping method. A copy made before Surface cleanup existed keeps the destination’s cleanup choice; earlier Auto/Off copies transfer that choice; paste does not switch its softening method. Sources, their placement, per-part Hold Shape, joins, custom material overrides and Sticky/World mode stay with the destination. Pasting is one Undo operation. Soft Dough generates its grooves on the destination surface rather than copying source-model helper objects. Older models may first need their Update Form Variation or surface-detail buttons.

Secondary color and patch scale appear when Color mixing is above zero. Grain frequency is disabled when Surface grain is zero. On finishes such as Dirty Clay, find Mineral flecks under Additional finish controls; saved values are retained.

Open Wax, Glaze & Optical Finish for translucency, transmission, coat, metallic and iridescence controls. Lighting makes a large difference, especially for glossy, transparent and metallic finishes.

Gray viewport? Choose Material Preview or Rendered shading. If a custom material override is assigned, the generated clay shader controls do not edit that custom material.

The swatches above are actual Cycles renders. The Bumpy Clay sample is an earlier saved noise study: Hand-shaped amount 12, scale 3.6, Surface grain and Finger impressions 0, and Roughness 0.43. Type the Hand-shaped amount to go above the normal slider range. Its edited noise settings are saved in the Material Playground. For a new broad, squeezed-clay form, start with Shape style and Hand pressure; you do not need to edit shader or geometry nodes. The earlier noise controls remain under More shape controls. Body and eye regions can use the same preset family. The included Material Playground lets you inspect and customize every finish.

Raku Clay: glaze, patches and crackle

Choose Raku Clay for a dark fired-ceramic finish with warm mineral-colored patches, fine glaze grain and restrained colored sheen. Open Material-Playground.blend to inspect the example. The default is one reference-inspired Raku appearance; it does not represent every Raku tradition.

ControlRaku behavior
Clay color / Second clay colorDark glaze color and the warm patch color. Turn on Keep my colors before switching presets to preserve your palette.
Color mixingPatch coverage. Zero gives continuous dark glaze; try 0.35–0.7 for progressively more warm patches.
Color patch scalePatch frequency. Lower values make broad patches; higher values make smaller patches. Default: 4.5.
Color variation seedChanges pigment mottling within the glaze. It keeps the glaze/earthen-patch boundary, physical grain and fine crazing in place.
Roughness / GlazeGloss of the dark glaze. Warm patches stay rougher. For a subdued finish, raise Roughness and lower Glaze.
Metallic / IridescenceStrength of the metallic and bronze-blue colored sheen. Set both to 0 for a nonmetallic black-glaze interpretation. These are artistic appearance controls, not a kiln simulation.
Surface grain / Grain frequencyFine fired grain and uneven glaze relief. Lower grain for smoother glazing.
Glaze crackleRaku-specific hairline glaze crazing when Crack style is Soft Dough. Default 0.12; 0 removes it. This is shader relief, with no extra mesh subdivision. With Dry Fractures the secondary control is labeled Fine fissures.
Layout density / Crack seedLayout density sets the spacing of the fine glaze crazing; higher values make smaller cells. Crack seed chooses a different layout, leaving body proportions and warm patches alone. The separate Crack scale control changes the surface splits, not this glaze network.
Crack displacementStill controls real clay splits separately; leave it at 0 for intact ceramic with only glaze crazing.

For a pale crackle look, set Clay color to an ivory tone, Color mixing to 0, Metallic and Iridescence to 0, and keep Crack style Soft Dough and raise Glaze crackle to about 0.6. Lower Surface grain to 0.15 for a smoother glaze. All seventeen finishes are also available independently for the eye white, iris and pupil.

What the finish is based on

The Raku Museum describes the black and red glazes of Japanese Raku. Western post-firing reduction can instead produce carbon-darkened surfaces and glaze crackle; copper reduction can create a metallic, multicolored sheen. See ceramic artist Adil Ghani’s copper-matte account and the ceramics demonstration reference, Making Raku. Pale markings in a photograph cannot by themselves be identified as unglazed clay: smoked bare clay often becomes dark.

SURFACE CONTROLS

Thumbprints, cracks and bite marks

Thumbprints

ControlTry this
Finger impressionsRaise it gently to make the ridges more visible.
Thumbprint size0.55 for small prints; 1 for default; 1.4 for larger prints. Centers stay in place.
Print densityChange how closely prints are spaced.
Thumbprint stretchTry 1, 3 and 5: round patches become longer and narrower with similar area. Surface-angle correction reduces unintended diagonal stretching.
Print irregularityBend the flow of the ridges.
Fingerprint seedRearrange the positions, orientations and ridge families without changing color patches, cracks or geometry. Try 0, 7 and 38, or the refresh arrow. Returning to 0 restores the initial layout for these settings.

The thumbprint generator grows a fresh set of ridge patterns for each Fingerprint seed, including loops, arches, whorls, ridge endings and forks. Use the seed's refresh arrow (Generate Thumbprints) to try another set. Uneven pressure softens each impression into the clay. The generated relief is packed inside your .blend, so it needs no external texture files.

Thumbprints are shader relief, so their size does not remesh the body. On an older saved material, click Update Thumbprints to adopt the generator. Your values and a complete previous-material backup are retained. Fingerprint seed transfers with Clay Finish and Fingerprints & Cracks Copy/Paste.

Soft Dough cracks

Crack styleSoft Dough gives long, rounded grooves that wind around the surface, with fuller middles and pinched tips. Dry Fractures gives cellular dried-earth cracks. Compression gives broad squeezed lumps with rounded intersections; see the Compression chapter for its controls.
Crack displacementActual recessed depth in the mesh. Zero turns the geometry displacement off.

Crack scaleDry Fractures: resize the connected plate network. Soft Dough: shorten or lengthen grooves along their surface paths, from the same middle. 1.00 is the baseline length.

Crack color

These color controls apply to Soft Dough and Dry Fractures. Compression replaces crack paint with inherited material color and Optional tint.

The swatch automatically follows the clay color. Dry Fractures chooses a warm brown shade. Editing the swatch sets a custom color; the reset arrow restores automatic coloring. These values transfer with Clay Finish and Fingerprints & Cracks.

On real Soft Dough grooves, the chosen pigment fills the interior and blends softly into the clay at the edges. Shrinking a groove keeps its color strength. Soft Dough uses the same surface groove shape for displacement and color, so pigment follows the recess. Editing crack settings on an older live model adopts this system automatically, preserving chosen settings and keeping the previous graph, material and helper meshes as backups. Reflections and lighting still affect how the pigment appears.

For Dry Fractures, this color affects both the main recessed network and the smaller shader creases. Set Fine fissures to 0 to isolate the main cracks. Crack width controls how broad the main colored recesses are. Lighting and the clay pigment still affect the rendered color.

Dry Cracked Earth: rounded clay cells

The preset blends pale cream, ochre and tan clay, with softly raised cells of unequal fullness and connected brown creases. A satin finish and broad hand-formed unevenness soften the surface. The boundaries retain their cell structure with small irregularities. Fine fissures adds varied-width interior creases across the plate faces; most are visibly wider than hairlines. These are shallow shader cracks, independent of the main mesh displacement. Fine fissures controls how many branches appear: lower values remove branches without fading or moving the ones that remain. Fissure ends taper smoothly to avoid angular shading cutoffs. Set it to 0 to view only the larger fractures. Crack color now fills the recessed walls and floors while leaving raised clay cells untinted; glossy highlights still reflect the scene lighting.

ControlDry Fractures behavior
Crack scaleResize the connected network continuously. Below 1 gives smaller plates; above 1 gives larger plates. The network stays joined. This changes the paths without randomizing the seed.
Crack widthChoose Fine, Medium, Wide or Custom. Custom exposes Width factor: 1.0 is Medium, 0.5 is Fine and 2.0 is Wide. The factor controls the opening relative to each cell; actual gaps vary, and larger cells give wider gaps. Width changes retain the seed and current boundary paths.
Layout densitySet the baseline number and spacing of plates. Crack scale multiplies their size.
Crack detailAdd irregularity along the connected cell boundaries.
Crack displacementControl real cavity depth. Fine fissures controls the amount of smaller shader cracks.

The preset starts at displacement 0.60, Crack width Custom with Width factor 1.5, detail 0.55, density 7, scale 1 and Standard quality. Fine fissures starts at 0.06, Surface grain at 0.10, Roughness at 0.45, and Finger impressions and Mineral flecks at zero. Hand-shaped amount is 6 at scale 3.5. Color mixing starts at 0.80, Color variation at 0.50 and Color patch scale at 6.5. Lower Color mixing for less ochre; lower Color patch scale for larger patches. Adjust the exposed Crack color to change the creases. On an older saved material, Update Crack Shading adopts the revised color coverage and fine-fissure amount behavior with a full previous-material backup. Editing a finish control also applies this shader repair; it preserves the mesh and settings.

On an existing model, click Update Dry Fractures once to adopt this behavior while retaining your settings and editable parts. The complete previous graph, material and helper meshes remain backed up. To use the preset defaults, select Dry Cracked Earth in Clay Finish again.

Soft Dough: flowing surface grooves

Soft Dough follows smooth paths around the actual clay surface. Each groove opens through its middle and closes to a pinched tip. The generator leaves clearance between paths and opens closed contours, reducing small rings, crossings and broad endpoint patches.

Choose a layout with Crack seed, Layout density and Crack detail. Crack coverage controls how much appears. Crack scale shortens or lengthens the grooves along those paths. Use the Crack width dropdown to choose Fine, Medium, Wide or Custom. New ordinary models start at Medium. The named widths are sized to the model and change only width. Custom retains the current width and reveals an editable Opening length. No seed refresh is needed.

Under Custom, Opening measures the full opening at the widest middle. The tips are narrower. Blender displays a length using your scene units; when no unit system is selected, the field is marked BU for Blender units. For a uniformly scaled model, it includes the whole-model handle’s scale. If uneven scaling or shear makes the world width vary by direction, the label becomes Opening (local) and reports the model-space opening instead. Changing Layout density keeps the opening setting steady while the paths and spacing change. At high density, crowded paths may shorten or disappear to leave clearance.

Installing the new controls keeps your saved opening; values between the named widths appear as Custom. On older live models, editing Soft Dough settings adopts the surface-curve system automatically while preserving the current width. Your chosen colors, settings and editable parts remain; previous graph, material and helper data are kept as backups. After reshaping parts or editing the layout, allow the surface to finish updating.

Choose quality for the view you need

Standard is the starting choice for finished renders: it adds samples around crack walls while keeping a bounded triangle count. Base mesh is a lighter working view with no added crack-wall geometry. It can show steps or pinches where a narrow groove crosses too few faces. Reducing displacement alone cannot add the missing faces.

Start with Standard and displacement around 0.25–0.50. After editing, wait for refinement; use Full Quality Now if adaptive preview is enabled. Inspect the surface from the side and in your final lighting. More densely packed, narrower or deeper grooves need more samples. If a wall still looks faceted, try Close-up, raise the model’s Resolution, or reduce density or depth. A slightly wider opening also gives the wall more room to descend smoothly.

Quality has a geometry cost. Standard stays within 4× the base triangle count; Close-up stays within 16×. Dense layouts share that budget across more walls, so the added detail is finite. Base mesh keeps the original count. Full Quality Now, saving and baking finish pending refinement. Judge the settled result before rendering.

Playful bite marks

Open Bite Marks and enable them. Size sets the arch size; Depth sets the indentation; Coverage controls how many stamps appear. Variation changes whole-arch pressure and size. Bite seed moves only the bites. These are stylized tooth impressions, not a removed mouthful. Tight corners and thin parts can show incomplete contacts; try another seed, less depth or more surface resolution.

Cracks and bites become part of Bake Mesh Copy. Fingerprints, grain and color patterns remain shader effects; they do not become sculpted vertices automatically.

EYE CONTROLS

Create, place and customize clay eyes

Add and place an eye

  1. Open Clay Eyes, choose a pupil shape, and click Place Eye on Surface.
  2. Click the clay where the eye belongs. To move an existing eye, select it and click Reposition Selected Eye. Cancel with Esc.
  3. Adjust Eye diameter, White bulge and Sink into surface until it sits comfortably.
  4. Add a second eye. Adjust pupil size, rotation and look direction to give the character an expression.

Use clay presets on the pupil or white

Select the eye. In Clay Eyes, set the finish for its white, iris and pupil independently. Try a waxy white with a glossy Bubble Gum heart, or a matte white and Raku Clay pupil. Colors are also independent. The iris is optional.

Each preset region exposes Roughness, Surface grain and Mineral flecks beneath its selector. Set Mineral flecks to 0 to remove speckles from just that region. More finish controls expands color mixing, impressions, fissures and optical controls. Eye cracks affect shading only. Each region remembers its adjustments for each preset, including after switching away and back or saving the file. Classic Eye retains its original shared classic controls.

Prefer dragging from the Asset Browser?

Click Enable Eye Asset Library. Open an Asset Browser, choose the Meld Clay eye library, and drag in a preset. Use the placement tool afterward to seat and orient it on your character. Save Blender preferences if you want the added asset library available next time.

Pick proportions before final eye placement. Eyes follow a surface attachment but do not bend around it. Large form changes can call for repositioning. Smaller eyes usually fit highly curved cheeks better.

Eye parameters regenerate editable meshes. They are not blinking or animation controls. Changing parameters after manual vertex editing can replace those manual edits. A baked character body and its eyes are separate objects; include both when exporting.

CLAY RELIEF

Lumps and squeezes

Turn the connected Dry Fractures pattern into broad clay lumps and squeezed valleys. Compression softens the places where several boundaries meet.

Actual Blender renders of the same original clay pebble, seed, finish, camera and lighting. Only Treatment changes. These are surface-relief recipes; the Shape style dropdown is a separate way to round and press the source parts.

Start with a treatment

  1. Select a live clay model. In Fingerprints & Cracks, choose Crack style → Compression. First selection starts with Gentle and Standard quality; a saved Compression choice restores its own settings.
  2. Compare Gentle, Clumped and Pressed. Orbit the surface, then choose a seed you like.
  3. Adjust Compression strength, Lump size or Valley width. Leave Valley color on Inherit material first. Try Optional tint only if the valleys need a color accent.

Compression controls

Choose Crack style → Compression in Fingerprints & Cracks for broad, worked-clay relief. It builds on Dry Fractures with rounded intersections, continuous material color and no secondary fissures, including Raku glaze crazing. It does not change your source rounding, hand pressure or join rules. See the illustrated treatments.

Older saved Compression models adopt the rounded junctions on their next geometry edit. Change strength once and put it back if you want to rebuild without changing your seed. Previous graphs and materials are retained for recovery. Standard or Close-up can help sampling, but extreme density, depth and narrow valleys still need sufficient Resolution.

Keep it soft and readable

For rough valleys, wait for refinement, try Close-up, increase Resolution, lower density or strength, or use wider valleys. To inspect the geometry, use a MatCap with Object Color set to Object and cavity enabled. Return to Material Preview or Rendered to judge the finish.

Rounded junctions add no global subdivision stage, but filtering the relief takes additional computation. Existing pressed joins and deliberately sharp source features remain separate; Compression does not smooth the whole character or promise that every extreme setting fits every shape.

SHAPE EXPLORATION

Model movement, texture space and seeds

Move the whole character

Use Move Whole Model under Movement & Textures. Move, rotate or scale that handle to keep the body and source parts together. Move an individual cage in Edit Parts to reshape the character.

Sticky or World?

Texture modeWhat you see
Sticky (default)Patterns stay attached when the whole model moves, rotates or scales.
WorldPatterns are sampled from the surrounding space. Moving the model changes the pattern on it.

Sticky does not mean textures remain identical after every topology-changing source edit. It is designed for moving the whole clay model. World mode also affects procedural geometry details such as cracks.

Try another clay shape

Use Shape & Melding → Shape style to choose Palm rolled, Thumb pressed or Gently kneaded. The recipes use Source rounding, Knead / soften and broad Hand pressure. Change Random seed for another repeatable pressure arrangement. Choose your shape before final eye placement. Compare the three styles.

Adjust the original part proportions

Use Edit Parts to deliberately widen a body, enlarge a foot or move a limb. The earlier Form variation control remains under More shape controls: it applies seeded axis scaling to individual parts before melding. It is not an attachment-aware character-proportion tool. Zero restores the original proportions. High values can break shallow overlaps; reduce the amount or move the source parts closer. The included Form Playground preserves this earlier study.

Broad hand pressure or surface noise?

Hand pressure makes smooth, broad squeezes that follow each piece’s size. Pressure areas sets their number and Pressure breadth sets their spread. For rougher surface unevenness, open More shape controls and adjust Hand-shaped amount and Hand-shaped scale. Those earlier noise controls remain independent; lower scale makes broader noise. The named Shape styles reset Hand-shaped amount to zero.

What is Midlevel?

It shifts the neutral point of normal displacement. Around 0.5 is neutral; lower values add fullness and higher values reduce it. It is separate from Inflate / deflate. A named Shape style starts at Midlevel 0.5 and Inflate / deflate 0.

The main Random seed is global. Use Crack seed or Bite seed when you only want those details to move.

VIEWPORT QUALITY

Adaptive preview and performance

Meld Clay regenerates the live surface when you reshape its parts. Resolution and the size of that live model have the biggest effect on responsiveness.

  1. Enable Adaptive preview under Shape & Melding.
  2. Start with Moving quality around 0.5. The surface becomes lighter while you move parts.
  3. Set Refine after to the pause you prefer. Full detail returns once editing slows.
  4. Use Full Quality Now to inspect the final surface immediately.
OptionTradeoff
Use Faster PreviewEnables additional temporary approximations for movement.
Fast fusion while movingSimplifies the moving surface and its joins temporarily. The final model is retained.
Light material while movingTemporarily uses a simpler preview shader. Full shading returns after refinement.
ResolutionMore detail, more meshing work. Try 96–144 while blocking out; increase for finishing.
Surface cleanupAuto gently reduces small remeshing steps independently of Knead / soften. Off skips that pass.
Knead / softenNamed Shape styles start at 45. Higher values continue smoothing the melded surface; use Hold Shape to protect important source contours.
Crack qualityUse Standard for finished renders. Base mesh is lighter while shaping; Close-up adds sampling for demanding narrow, dense or deep grooves.

Does moving a leg update only that leg?

No. The current model still evaluates a combined surface. Shader graphs and join-setting data are reused where possible, but this is not a local remesher. A scene with hundreds of millions of triangles can still be limited by memory, rendering or other objects even if one clay model is small.

Other animals getting in the way?

Edit Parts focuses source cages on the current animal. Use the top-level Hide Cages toggle for an uncluttered view. For a very heavy scene, hide finished animals’ collections while working on one character, or use baked copies for finished work.

The add-on does not lower final render quality when adaptive preview is enabled. Final output still costs time and memory to evaluate. There is no universal frame-rate or maximum-triangle-count guarantee.

OUTPUT AND SOURCE RECOVERY

Bake, export and recover source parts

Bake Mesh Copy

Under Finish & Utilities, click Bake Mesh Copy to create a normal mesh of the full-quality result. The editable model is retained in the Outliner. Use the baked copy for manual sculpting, cleanup or export.

Real cracks and bites are geometry in this copy. Procedural materials remain Blender materials. Fingerprints and grain are shader relief; exporting to another program may require separate texture baking and material setup. Eyes and accessories remain separate objects.

The modifier’s “Bake” panel

The Bake panel inside Blender’s Geometry Nodes modifier is Blender’s generic baking/cache interface. Its Packed target and Bake Path are storage options for supported node bakes. They are not the add-on’s Bake Mesh Copy button and are not needed for the normal Meld Clay workflow. Named Attributes entries list internal data used by the node graph; you do not need to edit them.

Restore Original Parts

Use this when you want the blockout back as ordinary editable objects. It detaches the source parts from the clay workflow and restores their visibility. Save your scene before changing which representation you want to keep.

Deleted the clay but kept the parts?

Select those remaining source objects and click Recover Selected Parts. This clears stale ownership when the original clay model no longer exists. Then select the desired rough parts and use Meld Selected Parts again.

Save versions of your scene

Keep a working .blend and a separate copy before major changes or model detail updates. Backed-up node/material data keeps old customizations, but a saved scene copy is the easiest way to revisit the whole previous state.

New details to explore

Fingerprint seed rearranges pressure patches and their ridge families independently of color and cracks. Thumbprint stretch ranges from round to long impressions. An older saved model keeps its current shader until Update Thumbprints is chosen, retaining the previous material as a backup.

End taper under a Pressed join narrows and softens its exposed ends. Try 0, 2 and 4; the number is a distance in crease widths. Fully closed contact loops have no endpoints. Join Copy/Paste includes taper; Hold Shape remains per source part.
