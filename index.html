Find a setting quickly

Use Search settings at the top of the Meld Clay panel or in the 3D Viewport header. The header field stays available when the sidebar scrolls; its filter button opens the matching controls. Both fields share one query. Type crack, pressure, hold or move to find controls and actions such as Move Whole Model. Matching settings appear as editable controls, grouped by their section, including controls normally behind collapsed sections. Search follows the selected clay model or eye. Disabled results show the setting or selection they require. Clear the search with its × to return to the normal panels. Searching itself changes no model settings.

This guide is for Meld Clay v1. Tested on Windows in Blender 4.5.0 and 5.1.2. Other operating systems and Blender versions have not been tested in this release.

GET SET UP

Install and update Meld Clay

First installation

  1. Extract the large Meld-Clay-v1.zip customer download.
  2. Inside its Installer folder, find meld_clay-1.0.0.zip. Leave this smaller ZIP zipped.
  3. In Blender, open Edit → Preferences → Add-ons. Open the small menu at the top right and choose Install from Disk.
  4. Select meld_clay-1.0.0.zip. Confirm installation and enable Meld Clay if Blender asks.
  5. Move your pointer into the 3D Viewport, press N, and open the Meld Clay tab.
Two ZIPs, two jobs. Extract the customer download. Install the smaller installer ZIP. Dragging the entire customer bundle into Blender will not install the add-on.

Requirements

Blender 4.5 or newer is required. This release was tested in Blender 4.5.0 and 5.1.2 on Windows. No external Python packages, paid renderer, textures, accounts or online connection are required to use the add-on. Cycles and Material Preview show the clay finishes; Solid shading is useful for shaping but does not show the full shader.

Updating an existing installation

  1. Save a separate copy of your scene.
  2. Install the newer installer ZIP using the same steps above, then fully close and restart Blender before opening your working scene.
  3. Select an existing live clay model. Its saved recipe values remain in Shape style: Custom. Choose a named Shape style to apply the new clay recipe, or Enable Clay Shaping to expose individual rounding and pressure controls with zero added effect. Saved per-part Hold Shape values are preserved. Adjust the Soft Dough controls directly to change its cracks. Use Update Thumbprints or Update Form Variation only when offered. Softening has a separate, explicit choice: Update Softening under Shape & Melding. Choosing a Shape style or Enable Clay Shaping also updates softening as needed. Otherwise, the saved method stays in place until you choose Update Softening. New models already use the current method. Read the cleanup and softening guide.

Your editable parts, settings and material choices are kept when you update. An older model may look a little different around its outline, cracks or joins, so save a copy first and compare the result before replacing your working file. Keep the matching installer and scene copy if you want to return to an older version. Baked copies stay separate from the editable model.

A missing manifest message?

The manifest is the small label inside the extension ZIP that tells Blender what it is installing. Install Installer → meld_clay-1.0.0.zip, not the large customer download or a ZIP of the project source. You do not need to edit a TOML file. During v1 preparation, replacement builds still show version 1.0.0; install the supplied ZIP from disk and restart Blender.

If the tab does not appear

Check that Meld Clay is enabled in Preferences, then look for its tab in a 3D Viewport, rather than the Shader Editor or Properties window. If an upgrade reports a Python import error, restart Blender and install the new ZIP again. Include the full error when requesting help.

Good building blocks

Use closed mesh solids with a little overlap. Thin sheets, open meshes, tiny floating details and barely touching surfaces may disappear or stay separate at low resolution. Curves and text can be converted to mesh in Blender first; this add-on’s melding input is mesh parts.

Adding or removing a part

Click the finished clay model in the scene and choose Edit Parts, then select the additional mesh. The target stays on that model when you select a loose part. Check the target name and click Add Selected: the part count increases and the surface updates immediately. The original becomes an editable source cage; it is not deleted. The added shape takes the target model's clay finish and surface settings.

Select an owned source and click Remove to detach it; the surface updates and the separate original returns. Join rules involving that part are removed too. Other joins keep their settings, and Undo restores the removed part and its rules together. If you added a part to the wrong model, edit that model's parts, select the misplaced source and Remove it, then add it to the intended model. For narrow horns or spikes, use the source part's Hold Shape under Join Controls to reduce kneading. Leave an accent separate if it should keep its own finish. To detach everything, use Restore Original Parts in Finish & Utilities.

If Meld Selected Parts is gray, read the hint below it: the selection may already belong to a clay model, contain an eye, or be in Edit Mode. Use Edit Parts to change an existing model.

SHAPE THE CLAY

Roll it, press it, knead it

Choose a Shape style for the body feel, then adjust only what you want to change. The recipes round your editable source pieces and add smooth, broad hand pressure before they meld.

New models start at Palm rolled. Choose Thumb pressed for fewer, broader compressions or Gently kneaded for overlapping soft squeezes. Keep Surface cleanup Auto for small bumps and stair-step edges. The named styles set Knead / soften 45 and Source rounding 1; pressure follows the size of each source piece. Your saved per-part Hold Shape stays in place.

Actual Blender renders of the same 54-face source ball with Hold Shape 0, the same seed, finish and lighting. Click a render to inspect it. These show the shape recipes; the fingerprints and clay finish are separate material controls.

ControlWhat to expect
Shape stylePalm rolled, Thumb pressed or Gently kneaded sets a complete body-shaping recipe. Custom keeps your current values. Editing a recipe value switches the dropdown to Custom without resetting the other values. A finish preset can also set the earlier surface noise and make the style read Custom; choose your finish first, then your Shape style for its complete recipe.
Source roundingTurn coarse source contours into a curved form before melding. 0 keeps the source contours; 1 allows full chosen rounding. Knead / soften and Hold Shape also affect the result.
Hand pressureBroad geometry squeezes, as a percentage of each source piece radius. 0 adds no pressure. It is separate from material grain and fingerprints.
Pressure areasHow many broad squeeze areas surround each source piece. More areas give more overlapping changes to the shape.
Pressure breadthHow far each squeeze spreads. Higher values produce broader, gentler areas; lower values concentrate them.
Knead / soften0 disables source rounding as well as artistic kneading. 45 gives the full selected Source rounding; higher values continue softening the melded surface. Hand pressure remains independent.
Surface cleanupAuto reduces small bumps and stair-step edges, even at Knead / soften 0 or on held parts. Off skips this cleanup; it does not turn off hand pressure or material texture. Cleanup alone cannot turn a faceted source into a round clay ball.
ResolutionHow finely the underlying surface is rebuilt. Higher values allow smaller details, with more processing and memory.
Hold ShapeProtect one source part from rounding and hand pressure. On a one-part model, edit it directly below Knead / soften or search hold. On a multi-part model, use Edit Parts, select a source, and adjust Hold Shape in Join Controls.
More shape controlsContains Form variation and the earlier Hand-shaped amount/scale noise. These remain available for saved looks and rougher effects. Named Shape styles set Form variation and Hand-shaped amount to 0.

A quick clay-ball exercise

  1. Save a working copy and select a one-part clay ball. Choose Palm rolled. If its source has protection, set Hold Shape 0 below Knead / soften.
  2. Compare Palm rolled → Thumb pressed → Gently kneaded using the same Random seed. Orbit the silhouette and back of the ball.
  3. Keep your favorite style, then change Hand pressure gradually. The dropdown now says Custom because you made your own recipe. Adjust Pressure breadth if a squeeze is too concentrated.
  4. Try Knead / soften 0 → 45 → 120 → 45. At zero, source rounding stops; pressure can still be visible. Use lower Hand pressure or Source rounding for a gentler change.
  5. Keep Full-detail editing enabled and use Full Quality Now if refinement is pending. In Solid shading, a MatCap with Color set to Object and optional Cavity reveals the actual surface. Return to Material Preview to judge the finish.

Keep fingers, knuckles and deliberate small details

To protect a particular part, use Edit Parts, select its source and increase Hold Shape in Join Controls. Lower Knead / soften, Source rounding or Hand pressure if the whole model changes too far. Compare seams and small tips after a shape change: the existing joins, cracks and bites follow the changed surface. The presets retain the source meshes and join rules, but do not guarantee every small contour.

Existing models: choose when to change

Opening an older file retains its saved recipe values in Custom. See Install & update for surface corrections in the current build. Choose a named Shape style to adopt a new recipe, or use Enable Clay Shaping for zero added rounding and pressure before adjusting individual controls. Existing Hold Shape values are preserved, so a protected low-poly ball may need less Hold before it rounds fully. If an old model asks for Update Form Variation, run that prerequisite first. Update Softening is also available for older softening graphs; enabling the new clay shaping updates softening as needed. These explicit updates retain previous data for recovery.

Shape & Melding Copy/Paste includes the shape recipe and individual shaping values, Surface cleanup, preview preferences and Random seed. It does not copy source geometry, part placement, joins, materials or per-part Hold Shape. An older destination may ask for Update Softening and Enable Clay Shaping first. A copied style adapts its pressure to the destination pieces. A copy from before clay shaping existed sets the new rounding and pressure to 0 and selects Custom, retaining the destination’s shaping method. A pre-cleanup copy retains the destination’s cleanup choice; an earlier Auto/Off copy transfers that choice. Read the clipboard boundaries.

SHAPE & CHARACTER

Join rules and Hold Shape

Edit one connection

  1. Click Edit Parts.
  2. Select one cage, then Shift-select the cage it touches.
  3. Open Join Controls and click Edit Selected Join. These two selected parts determine the rule you edit.
  4. Choose the style and adjust its settings. Hide Cages near the top clears your view; cages also pause automatically during crease edits and return after about 1.5 seconds.
ControlUse it for
BlendedA soft transition between overlapping parts.
PressedAn indented seam, as though separate lumps were pressed together.
Crease strengthHow pronounced the indentation is. Start small.
Crease widthHow broadly the seam spreads around the contact.
Hold ShapeBlend one part between softer and held contours, from 0 to 1. This belongs to the part and can affect every contact involving it. Round parts may change less than angular parts.

A model made from one source also exposes Hold Shape in Shape & Melding and search. It is the same source-part value; you do not need a join rule or Edit Parts to use it.

Different legs and head seams?

Yes. Select each pair and give it its own rule: a leg meeting the body can have a different seam from a head meeting the body. Hold Shape belongs to the selected part, so changing it can affect several joins around that piece. Nearby seams can also influence the same area. Adjust gradually and orbit the model to check the result.

Keep the spaces between fingers

A Pressed rule adds a crease at its selected contact. The spaces between unrelated parts, such as fingers, stay open. Openings still depend on the source spacing, softening and Resolution. The Rock Dude arm study shows both finger separations and a narrow opening at Resolution 100.

Keep Full-detail editing enabled while adjusting Hold Shape, so you can judge the outline, cracks and bite marks together. Save a copy before experimenting with a shape you already like.

Copy a join you like

  1. Edit the source join and click Copy Settings.
  2. Select the destination pair and click Edit Selected Join.
  3. Click Paste Settings.

This transfers the join style and crease settings. Check the destination parts’ Hold Shape separately because it is a part setting.

Selection feels confusing?

Selected parts, Saved join rules and Editing this join are separate boxes. A red notice identifies a selected pair with no rule, or a listed rule that differs from your selection. The selected pair and the highlighted list row can refer to different joins. Edit Selected Join follows your two selected cages. Edit Listed Join follows the highlighted rule. Removing a rule is not necessary to select another pair. Object identity, rather than the displayed name, identifies a part.

Copy settings between clay models

Use the Copy icon at the right of Clay Finish, Shape & Melding or Fingerprints & Cracks. Select the destination model and click Paste beside the same title. Each section has its own clipboard. Use Fingerprints & Cracks to transfer only surface details. Shape includes the chosen Shape style and its rounding/pressure values, Surface cleanup, preview preferences and Random seed. Gray viewport? Choose Material Preview or Rendered shading. If a custom material override is assigned, the generated clay shader controls do not edit that custom material.

Raku Clay: glaze, patches and crackle

Choose Raku Clay for a dark fired-ceramic finish with warm mineral-colored patches, fine glaze grain and restrained colored sheen. Open Material-Playground.blend to inspect the example. The default is one reference-inspired Raku appearance; it does not represent every Raku tradition.

ControlRaku behavior
Clay color / Second clay colorDark glaze color and the warm patch color. Turn on Keep my colors before switching presets to preserve your palette.
Color mixingPatch coverage. Zero gives continuous dark glaze; try 0.35–0.7 for progressively more warm patches.
Color patch scalePatch frequency. Lower values make broad patches; higher values make smaller patches. Default: 4.5.

For a pale crackle look, set Clay color to an ivory tone, Color mixing to 0, Metallic and Iridescence to 0, and keep Crack style Soft Dough and raise Glaze crackle to about 0.6. Lower Surface grain to 0.15 for a smoother glaze. All seventeen finishes are also available independently for the eye white, iris and pupil.

What the finish is based on

The Raku Museum describes the black and red glazes of Japanese Raku. Western post-firing reduction can instead produce carbon-darkened surfaces and glaze crackle; copper reduction can create a metallic, multicolored sheen. See ceramic artist Adil Ghani’s copper-matte account and the ceramics demonstration reference, Making Raku. Pale markings in a photograph cannot by themselves be identified as unglazed clay: smoked bare clay often becomes dark.

Choose the scale of the lumps first. Larger Lump size or lower Layout density gives broader forms. Smaller Lump size or higher density gives more compact repetition. Both can rearrange the pattern, so settle them before choosing your favorite seed.

Select those remaining source objects and click Recover Selected Parts. This clears stale ownership when the original clay model no longer exists. Then select the desired rough parts and use Meld Selected Parts again.

Save versions of your scene

Save a separate copy before a major change or an update to an older model. Give versions clear names so you can return to a shape or finish you liked.

New details to explore

Fingerprint seed rearranges pressure patches and their ridge families independently of color and cracks. Thumbprint stretch ranges from round to long impressions. An older saved model keeps its current shader until Update Thumbprints is chosen, retaining the previous material as a backup.

ARTISTIC STUDY · 15–25 MINUTES

A weathered shell. A soft little runner.

Meet the Tidepool Courier. One precious pearl, a long way home, and absolutely no intention of slowing down.

Included with Meld Clay v1. Use the current installer from your Gumroad download. The editable Courier files are included there; this lesson and its pictures are also available online.

Give the detail a reason

The shell has spent its life knocking against tidepool rocks. The face, hands and flippers need to look lively and flexible. A crack across every finger would make the whole creature feel brittle. Crack exposure lets those parts share one live clay model without receiving the same amount of surface cracking.

This is an original Meld Clay study. The lifted rear flipper, reaching hand and forward lean carry the gesture; the shell gives that movement something heavy to pull against. Before adding more details, check that you can still read the pose from across the room.

These Blender files are included with the Gumroad download, under Guide → projects → tidepool-courier. They were saved in Blender 4.5 and checked with Meld Clay v1. Save a personal working copy first.

1. See what the whole-model treatment does

  1. Open 01-Tidepool-Courier-All-Cracked.blend. Select Tidepool Courier | live clay. Switch to Material Preview to see the clay colors, or Solid shading to concentrate on its shape.
  2. Look at the shell, then at the face, hand and lifted flipper. The starter uses Fingerprints & Cracks → Crack style → Dry Fractures across the whole model.
  3. Keep this crack pattern for now. The next change is where it shows, so you can compare the result clearly.

2. Protect the face first

  1. Click Edit Parts. In the Outliner, expand Tidepool Courier | live clay · Parts. Select Face | curious head. You can also click its cage in the viewport.
  2. Open Join Controls → Selected part → Crack exposure. Set it to 0.00. Search settings for Crack exposure if the panel is crowded.
  3. Select Face | soft muzzle and set its exposure to 0.00 too. Look around the muzzle as well as straight at the eyes.
  4. Try 0.50 on the head, then return to 0.00. Half exposure softens the existing treatment; it does not move or randomize the cracks.
0.00 = protected. 1.00 = full treatment. The first exposure edit prepares the model and can take a few seconds. Later exposure edits reuse that preparation. The visible result blends across overlapping parts, so a join is a gradual handoff rather than a hard painted border.

3. Decide which clay should look weathered

Source partsCrack exposureArtistic purpose

Body, Neck and both Face parts0.00A smooth face and flexible center.

Select each source individually and set its value. This control affects the selected part; it is not a button that applies a value to every selected cage. The eyes and pearl are separate objects and do not need these settings.

Click Finish Editing Parts and orbit the result. If cracking remains around a contact, check the part on the other side too. Protecting the head alone does not also protect an overlapping muzzle.

4. Make it yours

  • Older traveler: try 0.20 on the head for a hint of wear, keeping the muzzle and fingers at zero.
  • Soft sea candy: change Crack style to Soft Dough, then check the shell depth and width. Exposure still controls where that treatment appears.
  • A shell pressed by the tide: try Compression → Treatment → Gentle. The protected body keeps its soft outline while the shell receives the broad relief. Expect a different appearance from the pictured Dry Fractures study.

Exposure controls this model’s crack treatment. Pressed join seams, bite marks, fingerprints and separate glaze crazing have their own settings. A custom override material also keeps its own shading. Exposure does not assign a different crack style or seed to each part.

5. Check the edit, then save

  1. Change the head from 0.00 to 0.50 and back. Try Ctrl+Z, then Ctrl+Shift+Z. Check both its value and the visible surface.
  2. Move a source slightly, change another part’s exposure, then undo both edits. Redo them in order. Let the surface settle between checks.
  3. Save your own copy, reopen it, and inspect the face, shell and hand. Compare with the finished reference if you lose your place.

Now give the rear flipper a more expressive sweep in the live Edit Mode lesson.

LIVE SHAPING · 10–15 MINUTES

Move a few vertices. Watch the clay follow.

The cage is the handle. The finished clay is what you judge. Give the Courier’s lifted flipper a longer, upward sweep while its live surface stays visible.

Included with Meld Clay v1. Use the current installer from your Gumroad download. The editable Courier files are included there; this lesson and its pictures are also available online.

Both files keep the source meshes, live clay and exposure settings. The starter opens with the lifted flipper source selected in Object Mode.

What you are actually editing

A live Meld model has simple source meshes underneath its finished surface. Edit Parts reveals those objects. Blender’s Edit Mode lets you change the vertices of one of those sources. The surrounding clay updates while you remain in Edit Mode.

Two steps into the clay. With the finished clay selected, press Tab to open Edit Parts. Select Foot | lifted flipper, then press Tab again to edit its vertices. A baked copy is an ordinary mesh; its vertices do not drive the live model.

Find the face through the shell

A big shell can make a small face hard to pick out. Before shaping the flipper, try the two cage views on the Courier’s head.

  1. In Object Mode, open Edit Parts and select Face | curious head. Orbit to a low angle so the shell sits behind the face.
  2. Choose Clear Cage View above Edit Parts. The active head stands out while nearby cage grids help you judge how the pieces overlap.
  3. Choose Focus. The surrounding cages become quieter outlines, leaving the face easier to follow. Switch back whenever you want more context.
  4. Press Tab to edit the head’s vertices. The choices adjust the outer outlines while Blender keeps its normal vertex, edge and face selection display. Press Tab to leave mesh Edit Mode, then select Foot | lifted flipper for the exercise below.

While you move, scale or rotate a part, or adjust its shape and Crack exposure, the cages briefly clear so you can judge the clay. They return after a short pause. In mesh Edit Mode, Blender keeps the editing handles visible.

Rendered Courier cage studies, shown from the same angle. Your viewport lighting and shading can look different; the choices only change the cage view, not the clay or its render.

Use Hide Cages for an unobstructed look, or Finish Editing Parts to return to the finished model. If styling pauses, check the sidebar note: full Wireframe view, view clipping or another visible mesh wire may need Blender’s normal drawing.

1. Open the right cage

  1. Open 03-Tidepool-Courier-Edit-Mode-Start.blend. The selected source is Foot | lifted flipper. If needed, find it inside the Courier’s Parts collection in the Outliner.
  2. In Shape & Melding, keep Live surface and Full-detail editing enabled.
  3. Move your pointer into the 3D Viewport and press Tab. The mode selector should now say Edit Mode. Press the top-row 1 for Vertex Select.
  4. Use Numpad 1 for Front View. Zoom in until you can pick the far-left end of the lifted flipper. The pictured pose faces toward positive X, so its trailing tip is on the left in this view.

2. Choose the tip, including its back side

  1. Press Alt+A to deselect the mesh vertices. Turn on X-Ray with Alt+Z so the selection reaches through the source.
  2. Use B and box-select roughly the outer third of the flipper, away from the ankle. Leave the ankle end unselected so the foot stays attached.
  3. Turn X-Ray off with Alt+Z. The selected vertices remain orange. Keep proportional editing off for this first exercise; you can explore it afterward.

3. Pull the gesture through the clay

  1. Set Transform Orientation to Global. Press G, X, type -0.38, and confirm. The selected tip moves farther back.
  2. Press G, Z, type 0.20, and confirm. The tip lifts.
  3. Stay in Edit Mode and watch the finished flipper. Orbit to check its thickness from the side. The model updates without applying a modifier or baking the clay.
  4. For a freer version, undo those moves and drag the tip into a sweep you like. Small vertex moves are easier to judge than pulling the foot far away from its ankle.

The reference moves all vertices whose local X position is below −0.20. Your box selection may be a little different, and that is fine: aim for a long, upward trailing shape with a solid ankle connection.

4. Undo, redo, then return to the finished view

  1. With the pointer over the viewport, press Ctrl+Z once to undo the upward move, then again for the backward move. Watch the source cage and clay return together.
  2. Press Ctrl+Shift+Z twice to redo. Leave a moment for the clay to settle if the scene is busy.
  3. Press Tab to return to Object Mode, then Finish Editing Parts for a clean view. Save a new working copy.

Keep the result pleasant to shape

Keep source meshes closed, and leave adjoining parts overlapping. Avoid folding faces through each other or stretching a tiny patch into a very thin spike. Add a little more source geometry when the cage needs another bend; the finished surface does not require you to hand-edit every one of its polygons.

Live means the surface follows your edits; it does not promise a fixed frame rate. Resolution, source complexity, deep cracks, bites and your machine all affect the pause. Keep full detail on when judging cracks. If the preview is paused, turn Live surface back on. If the surface needs to catch up after a large edit, use Full Quality Now once and inspect the result.

Eyes and the carried pearl are separate objects in this study. If you reshape the head or hand instead of the flipper, check their placement and move them to fit. The rear-flipper exercise keeps those attachments in place.
