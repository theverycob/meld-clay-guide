EMBER — MELD CLAY LEARNING PROJECT

Open START-HERE.html. Begin with 01-Ember-Blockout.blend; 02-Ember-Reference.blend is a saved editable example. Save your own copy. Both files were saved with Blender 4.5.0 for compatibility with Blender 4.5+.
The source model files are preserved. The saved reference and its dragon render predate the Shape style recipes; they provide construction and finish ideas, not an exact comparison with a newly built model.
Chapters 2 and 7 teach Palm rolled, Thumb pressed and Gently kneaded, then Source rounding and broad Hand pressure. New models start with Palm rolled and Knead / soften 45. Saved models retain their saved recipe values in Custom until you choose a named style or Enable Clay Shaping. If an earlier update is requested, follow the displayed action. Keep Surface cleanup Auto for small remeshing steps.
Hold Shape remains per source part. Single-part models show it directly in Shape & Melding and search; for multi-part models, use Edit Parts and select the source under Join Controls. More shape controls retains the earlier proportion and surface-noise options.
The three clay-ball comparison pictures are actual Blender renders using the current shape recipes, the same 54-face source, Hold Shape 0, and matching finish, lighting and seed.
